# Contributing

Contributions are welcome. Please follow these guidelines.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Update or add tests and docs.
4. Open a pull request with a clear description.

## Quality checks

- Run `terraform fmt -recursive` on Terraform changes.
- Update documentation if pipeline behavior changes.
- Ensure GitHub Actions workflows pass.

## Code style

- Keep YAML and Markdown consistent with existing formatting.
- Prefer small, focused changes.

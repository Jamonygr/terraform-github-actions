# Glossary

| Term | Definition |
|------|------------|
| OIDC | OpenID Connect, used for short-lived Azure authentication in GitHub Actions |
| State | Terraform state file stored in Azure Storage |
| Drift | Differences between actual infrastructure and Terraform configuration |
| SARIF | Static analysis results format used by GitHub Security |
| Plan | Terraform execution plan with proposed changes |
| Apply | Execution of the Terraform plan to update infrastructure |
| Canary | Small pre-production deployment to validate changes |
| Ephemeral env | Temporary environment created for PR validation |
